# 식사 장부 계산기

한 달치 급식 배달 장부 사진을 올리면, Gemini AI가 날짜별 손글씨 수량(예: `12+1`, `1+1+1+1`)을
읽어서 **총수량**과 **합계금(총수량 × 6,000원)** 을 자동으로 계산해 주는 웹사이트입니다.

## 사용 방법

1. `index.html`을 브라우저로 열거나, GitHub Pages 주소로 접속합니다.
2. **📸 사진 촬영** 또는 **🖼️ 앨범에서 선택**으로 장부 사진을 올립니다.
3. **🔍 숫자 세기 시작**을 누르면 10~30초 뒤 결과가 나옵니다.
4. 날짜별 표에서 잘못 읽은 칸이 있으면 수량을 직접 고칠 수 있고, 합계는 즉시 다시 계산됩니다.
5. 장부 아래에 적힌 총수량과 계산 결과가 다르면 ⚠️ 경고로 알려줍니다.

## 설정

- **개당 단가**: 기본 6,000원 (화면에서 변경 가능, 브라우저에 저장됨)
- **인식 모델**: 기본 Gemini 3.6 Flash. 인식이 부정확하면 ⚙️ 고급 설정에서 Gemini Pro로 변경

## API 키 전달 방법

보안을 위해 API 키는 코드에 들어 있지 않습니다. 두 가지 방법 중 하나로 넣습니다:

1. **링크로 전달 (권장)**: `https://<사이트주소>/#key=<API키>` 형태의 링크를 만들어
   공유하면, 처음 한 번 열었을 때 키가 그 브라우저에만 저장되고 주소에서는 지워집니다.
   이후에는 일반 주소로 접속해도 됩니다.
2. **직접 입력**: 화면 아래 ⚙️ 고급 설정에서 키를 입력합니다.

## 배포

`.github/workflows/pages.yml` 워크플로가 GitHub Pages로 자동 배포합니다.
무료 플랜에서는 저장소가 **공개(Public)** 여야 Pages를 쓸 수 있습니다.
저장소를 공개로 바꾼 뒤 워크플로를 한 번 실행하면
`https://<계정명>.github.io/somang/` 주소가 생깁니다.

## 전시·축제 모아보기 (`festivals/`)

전국의 전시·축제·공연 정보를 한 곳에서 보는 페이지입니다. 주소: `https://<계정명>.github.io/somang/festivals/`

- **데이터 출처**: 공공데이터포털의 한국관광공사 TourAPI 4.0(축제·공연·행사)과 한국문화정보원 공연전시정보. 브라우저에서 직접 호출하므로 서버가 필요 없습니다.
- **기능**: 종류(축제/전시/공연)·기간(진행 중/이번 주/이번 달/예정)·지역 필터, 검색, 정렬, 즐겨찾기, 상세 보기(소개글·공식 안내·지도 링크). 결과는 6시간 동안 브라우저에 캐시됩니다.
- **자동 수집**: `.github/workflows/collect.yml`이 매일 새벽 `scripts/collect.mjs`를 실행해 코엑스·킨텍스·벡스코 박람회 일정(키 불필요)과, 저장소 Secrets에 `DATA_GO_KR_KEY`가 있으면 공공 API 데이터까지 `festivals/data/events.json`에 저장합니다. 그래서 방문자는 키 없이도 전체 목록을 봅니다. Actions 탭에서 **Collect events**를 수동 실행할 수도 있습니다.
- **API 키**: [공공데이터포털](https://www.data.go.kr)에서 **한국관광공사_국문 관광정보 서비스_GW**와 **한국문화정보원_공연전시정보조회서비스**를 활용신청하면 받는 **일반 인증키(Decoding)** 하나로 두 서비스가 동작합니다. 식사 장부 계산기와 같은 방식으로 `#key=<인증키>` 링크 또는 ⚙️ 설정에서 입력합니다. Secrets 등록이 가장 간단하고, 브라우저에 직접 넣는 방식은 보조 수단입니다.
