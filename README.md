# 식사 장부 계산기

한 달치 급식 배달 장부 사진을 올리면, Gemini AI가 날짜별 손글씨 수량(예: `12+1`, `1+1+1+1`)을
읽어서 **총수량**과 **합계금(총수량 × 6,000원)** 을 자동으로 계산해 주는 웹사이트입니다.

## 사용 방법

1. `index.html`을 브라우저로 열거나, GitHub Pages 주소로 접속합니다.
2. **📸 사진 촬영** 또는 **🖼️ 앨범에서 선택**으로 장부 사진을 올립니다.
3. **🔍 숫자 세기 시작**을 누르면 10~30초 뒤 결과가 나옵니다.
4. 날짜별 표에서 잘못 읽은 칸이 있으면 수량을 직접 고칠 수 있고, 합계는 즉시 다시 계산됩니다.
5. 장부 아래에 적힌 총수량과 계산 결과가 다르면 ⚠️ 경고로 알려줍니다.

## 설정

- **개당 단가**: 기본 6,000원 (화면에서 변경 가능, 브라우저에 저장됨)
- **인식 모델**: 기본 Gemini 3.6 Flash. 인식이 부정확하면 ⚙️ 고급 설정에서 Gemini Pro로 변경

## API 키 전달 방법

보안을 위해 API 키는 코드에 들어 있지 않습니다. 두 가지 방법 중 하나로 넣습니다:

1. **링크로 전달 (권장)**: `https://<사이트주소>/#key=<API키>` 형태의 링크를 만들어
   공유하면, 처음 한 번 열었을 때 키가 그 브라우저에만 저장되고 주소에서는 지워집니다.
   이후에는 일반 주소로 접속해도 됩니다.
2. **직접 입력**: 화면 아래 ⚙️ 고급 설정에서 키를 입력합니다.

## 배포

`.github/workflows/pages.yml` 워크플로가 GitHub Pages로 자동 배포합니다.
무료 플랜에서는 저장소가 **공개(Public)** 여야 Pages를 쓸 수 있습니다.
저장소를 공개로 바꾼 뒤 워크플로를 한 번 실행하면
`https://<계정명>.github.io/somang/` 주소가 생깁니다.

## 전시·축제 모아보기 (`festivals/`)

전국의 전시·축제·공연 정보를 한 곳에서 보는 페이지입니다. 주소: `https://<계정명>.github.io/somang/festivals/`

- **데이터 출처**: 공공데이터포털의 한국관광공사 TourAPI 4.0(축제·공연·행사)과 한국문화정보원 공연전시정보. 브라우저에서 직접 호출하므로 서버가 필요 없습니다.
- **기능**: 종류(축제/전시/공연)·기간(진행 중/이번 주/이번 달/예정)·지역 필터, 검색, 정렬, 즐겨찾기, 상세 보기(소개글·공식 안내·지도 링크). 결과는 6시간 동안 브라우저에 캐시됩니다.
- **자동 수집**: `.github/workflows/collect.yml`이 매일 새벽 `scripts/collect.mjs`를 실행해 `festivals/data/events.json`에 저장합니다. 방문자는 키 없이도 전체 목록을 봅니다. Actions 탭에서 **Collect events**를 수동 실행할 수도 있습니다.
  - 키 없이 수집:
    - 전시·박람회: 코엑스·킨텍스·벡스코, 비짓서울 전시(서울관광재단)
    - 공연: 멜론티켓(콘서트·뮤지컬/연극·클래식·팬미팅·전시), NOL 티켓(뮤지컬·콘서트·연극·클래식·아동가족·전시)
    - 공공 문화행사: 서울문화포털 행사 달력, 경기문화재단 지지씨, 문체부 문화관광축제·지역축제 개최계획, KOBIZ 영화제, 국립중앙도서관·알라딘 작가 행사
    - 스포츠: 네이버 스포츠 경기 일정(KBO·K리그1·KBL·WKBL·V-리그, 앞으로 30일), LoL e스포츠, 마라톤온라인 대회 일정
    - 체험·클래스: 프립, 솜씨당, 웰촌 농촌체험마을, 국립공원 탐방프로그램, 숲나들e 자연휴양림 프로그램, 템플스테이(접속 대기열이 길면 그날은 건너뛰고 이전 데이터 유지)
    - 기타: 에버랜드·롯데월드 시즌 행사, 전국 5일장(전통시장 표준데이터 공개 파일), 팝플리 팝업스토어
  - 새 출처는 `scripts/sources/<이름>.mjs`에 한 파일씩 두고 `scripts/collect.mjs`의 `all` 목록에 등록합니다. 공용 도우미는 `scripts/lib.mjs`에 있습니다.
  - 경기도 공식 API(openapi.gg.go.kr)와 서울 열린데이터광장 API, 마르쉐는 해외 IP를 막아 GitHub Actions에서 쓸 수 없습니다. 각각 경기문화재단·서울문화포털·문체부 계획으로 대신합니다.
  - `DATA_GO_KR_KEY` Secret이 있으면: 한국관광공사 축제·행사, 한국문화정보원 공연·전시
  - `KOPIS_KEY` Secret이 있으면: [KOPIS 공연예술통합전산망](https://www.kopis.or.kr/por/cs/openapi/openApiList.do)의 전국 공연(뮤지컬·콘서트·연극)
  - **AI 분류**: 저장소 Secrets에 `ANTHROPIC_API_KEY`를 넣으면 수집 뒤 `scripts/classify.mjs`가 새로 들어온 행사를 Claude(기본 `claude-opus-5-5`, 저장소 Variables의 `AI_MODEL`로 변경)로 분류합니다. 결과는 각 항목의 `ai` 칸에 저장되어 다음 날에는 새 행사만 분류합니다. 키가 없거나 분류가 안 된 항목은 페이지의 키워드 규칙을 씁니다.
  - **데이터 재사용**: `festivals/data/events.json`은 그대로 가져다 쓸 수 있는 공개 파일입니다 (`https://gregosgosgos.github.io/somang/festivals/data/events.json`). 각 항목의 `ai`에는 다음이 들어 있습니다.
    | 칸 | 값 |
    |---|---|
    | `kind` / `genre` | 종류(fest 축제, expo 전시, fair 박람회, show 공연, popup 팝업, edu 체험·교육, sport 스포츠) / 공연 장르 |
    | `topics` | 주제 0~4개 (회화·조각, 역사·문화유산, 먹거리·특산물, 야간·야행 등 30종) |
    | `who` | 어울리는 동행 1~4개: 연인·데이트, 가족·아이, 부모님·효도, 친구, 혼자, 외국인, 반려동물 동반, 비즈니스·전문가 |
    | `age` | 연령대: 유아, 어린이, 청소년, 20대, 30대, 40대, 50대, 60대 이상 |
    | `mood` | 분위기 1~3개: 로맨틱, 힐링·여유, 활기찬·신나는, 감성·예술, 교육·배움, 트렌디·핫플, 전통·고즈넉, 럭셔리, 가성비 |
    | `setting` / `time` | 실내 · 야외 · 실내외 / 낮 · 밤 · 낮·밤 |
    | `cost` / `stay` | 무료 · 1만원 이하 · 1~3만원 · 3만원 이상 · 미상 / 1시간 이내 · 2~3시간 · 반나절 · 하루 이상 |
    | `blurb` | 한 줄 소개 (40~70자) |

    항목 자체에는 `price`(요금 문구, 있을 때), `famous`(문체부 문화관광축제 등급, 해당할 때), `also`(같은 행사를 함께 실은 다른 출처들)도 있습니다.

    분류 체계를 바꾸면 `scripts/classify.mjs`의 `TAXONOMY`와 `VERSION`을 올립니다. 그러면 다음 수집 때 전체를 다시 분류합니다.
  - 티켓 사이트는 개편되면 해당 출처만 비고 나머지는 유지됩니다. 실패 내역은 `events.json`의 `sources`와 Actions 로그에 남습니다. 로컬에서 일부 출처만 돌려 보려면 `SOURCES=nol,melon node scripts/collect.mjs`처럼 실행합니다 (NOL은 `npm i playwright` 필요).
- **API 키**: [공공데이터포털](https://www.data.go.kr)에서 **한국관광공사_국문 관광정보 서비스_GW**와 **한국문화정보원_공연전시정보조회서비스**를 활용신청하면 받는 **일반 인증키(Decoding)** 하나로 두 서비스가 동작합니다. 식사 장부 계산기와 같은 방식으로 `#key=<인증키>` 링크 또는 ⚙️ 설정에서 입력합니다. Secrets 등록이 가장 간단하고, 브라우저에 직접 넣는 방식은 보조 수단입니다.
